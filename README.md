# Simulador de Financiamento de Hardware 💻

Aplicação interativa em Python voltada para cálculos financeiros de investimentos em equipamentos de tecnologia. O sistema simula planos de parcelamento aplicando taxas de juros variáveis de forma automatizada com base nas regras de negócio estipuladas.

###  Tecnologias Utilizadas
- Python 3
- Estruturas de Controle Condicional (`if/else`)
- Formatação de Strings de dados monetários (`f-strings`)

###  Funcionalidades
- Cálculo de parcelamento com juros simples progressivos.
- Sistema automatizado de taxa zero para condições de pagamento de curto prazo.
- Proteção e validação contra entradas de dados incorretas do sistema.
